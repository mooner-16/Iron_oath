# IRON OATH — 중세 기사 1인칭 멀티플레이 칼싸움

브라우저에서 즐기는 마인크래프트풍 1인칭 기사 대전입니다. 서버 하나를 켜면 친구들이 주소만 열어서 같이 싸울 수 있어요.

## 실행 방법 (내 컴퓨터에서)

1. [Node.js](https://nodejs.org) 18 이상 설치
2. 이 폴더에서 터미널을 열고:

```bash
npm install
npm start
```

서버가 뜨면 접속 주소가 출력됩니다. (`http://localhost:3000`, 같은 와이파이 친구는 `http://192.168.x.x:3000`)

포트나 최대 인원 변경: `PORT=4000 MAX_PLAYERS=24 npm start`

## 설치 없이 인터넷에 올리기 (Render)

1. 이 폴더의 파일을 GitHub 저장소에 올립니다. (저장소 맨 위에 `package.json`, `server.js`가 바로 보여야 하고, `public` 폴더 안에 `index.html`, `game.js`가 있어야 합니다.)
2. Render → New → Web Service → 저장소 연결
3. Build Command `npm install` / Start Command `npm start` / Instance Type **Free**
4. 생긴 `https://….onrender.com` 주소를 친구들에게 보내면 끝

무료 요금제는 15분간 아무도 없으면 서버가 잠들어서, 첫 접속에 1분쯤 걸릴 수 있어요. 코드를 바꿔 GitHub에 올리면 Render가 자동으로 다시 배포합니다.

## 조작법

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 시점 |
| **Shift** | **달리기** (앞으로 갈 때, 스태미나 소모. 다 쓰면 20%까지 찰 때까지 못 뜀) |
| Space | 점프 |
| 좌클릭 | 공격 |
| 우클릭 또는 `F` (누르고 있기) | 방어 (피해 감소, 이동 느려짐) |
| **Q** | 기사별 고유 스킬 |
| **E** | 발차기 (공용) |
| Tab | 점수판 |
| **Esc** | 메뉴 (설정 / 캐릭터 선택 / 조작법 / 홈으로) |

터치패드라서 우클릭이 불편하면 `F`로 방어하세요.

## 기사와 스킬

| 기사 | 체력 | 속도 | 공격력 | 공격 간격 | 사거리 | 방어 감소 | Q 스킬 |
|---|---|---|---|---|---|---|---|
| 기사 | 100 | 5.2 | 22 | 0.70s | 2.6m | 60% | 📣 전투 함성 — 5초간 공격력 +30%, 이동 +20% (14초) |
| 대검 전사 | 120 | 4.2 | 40 | 1.20s | 3.2m | 40% | 🌀 회전 베기 — 주변 전방위 공격 + 밀어냄 (9초) |
| 결투가 | 80 | 6.4 | 13 | 0.38s | 2.3m | 35% | ⚡ 쇄도 — 전방 돌진 베기 (7초) |
| 방패 기사 | 150 | 3.8 | 17 | 0.85s | 2.3m | 85% | 🛡️ 방패 밀치기 — 방어 무시, 밀쳐내고 1.2초 기절 (10초) |

모든 기사 공용 **E 🦶 발차기**: 방어를 무시하고 6 피해 + 밀쳐내기 + 0.5초 기절 (5초). 방어만 하는 상대를 깰 때 쓰세요.

## 화면 구성

- 왼쪽 위 **미니맵**: 내가 보는 방향이 위쪽인 레이더. 빨간 점이 다른 기사
- 왼쪽 아래: 체력, **스태미나**, 버프/기절 상태
- 아래 가운데: **스킬 슬롯** (쿨다운 숫자 표시)
- 적을 때리면 데미지 숫자, 연속 처치하면 더블 킬 등 배너
- Esc 메뉴의 설정: 마우스 감도, 시야각, 볼륨, **그래픽 품질**(느린 컴퓨터는 "낮음"), 미니맵, 핑/FPS 표시, 화면 흔들림. 설정은 브라우저에 저장됩니다.
- 캐릭터 변경은 입장/부활 직후 8초 안에는 바로, 그 외에는 다음 부활 때 적용됩니다.

## 직접 고쳐 보기

기사나 스킬을 추가하거나 수치를 바꾸려면 `classes.js`만 수정하면 서버와 화면(선택 카드 포함)에 모두 반영됩니다. (새 기사의 외형은 `public/game.js`의 `LOOKS` 에 색상/투구 종류를 추가하세요.)

```
server.js        게임 서버 (웹 서버 + WebSocket). 명중/스킬/체력/부활 판정은 전부 서버가 결정
classes.js       기사, 스킬, 달리기, 맵 설정 (서버·화면 공용)
public/          index.html(UI·메뉴), game.js(Three.js 클라이언트: 모델·애니메이션·HUD)
test.mjs         서버 자동 테스트 (npm test)
```
